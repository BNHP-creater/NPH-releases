# NPH desktop previews

Download the Apple Silicon Mac preview from [Releases](https://github.com/BNHP-creater/NPH-releases/releases), or visit [storm.hk](https://storm.hk/download.html).

Requires macOS 13 or later. Preview builds are unsigned, are not notarized, and do not update automatically.

This repository distributes public installers and release notes. Each release records the installer size and SHA-256 for verification.
